Regressify catches unintended visual changes in web pages. It drives Chromium directly, so there is no Node or
Playwright to install, and you can use it from the command line or from the native desktop app.

## Start here

- [Getting started](/docs/getting-started/): install Regressify, create your first test suite, and run your first
  visual check.

## Desktop app

- [Using the desktop app](/docs/desktop-app/): open a workspace, edit suites, run visual tests, review results, and
  publish reports.

Use the sidebar to move between guides, the **On this page** list to jump between sections, and search (`Ctrl+K`, or
`Cmd+K` on macOS) to find a topic.
