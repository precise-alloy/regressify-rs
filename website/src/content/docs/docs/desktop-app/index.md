Regressify Desktop lets you edit tests, run them, and review visual reports in one window. Your YAML and JSON files
stay the source of truth, so you can still edit or commit them outside the app.

New to Regressify? Start with [Getting started](/docs/getting-started/).

:::note
On macOS, use `Cmd` where this guide says `Ctrl`, except `Ctrl+Space`. Click any screenshot to view it full screen.
:::

## In this guide

1. [Install](/docs/desktop-app/install/): install Regressify Desktop and the CLI on Windows, macOS, or Linux, and keep
   Windows builds up to date.
1. [Open a workspace](/docs/desktop-app/workspaces/): open a workspace folder, find suites and scenarios in the
   navigator, and check suite status on Overview.
1. [Edit suites](/docs/desktop-app/editing-suites/): create, rename, and edit suites with the Source and Fields editors,
   add actions, and save safely.
1. [Run tests](/docs/desktop-app/running-tests/): capture references, run visual tests, choose run settings, and follow
   progress and logs.
1. [Review results](/docs/desktop-app/reviewing-results/): compare captures with references, inspect capture details,
   approve changes, and clean up old test runs.
1. [Simplify images](/docs/desktop-app/simplify-images/): pixelate large images before each screenshot to shrink
   image-heavy captures without hiding changes.
1. [Use Git](/docs/desktop-app/git/): review, commit, and sync workspace changes with the built-in Git view.
1. [Publish reports](/docs/desktop-app/publishing-reports/): deploy reports to Azure Static Web Apps, Netlify, or
   Cloudflare Workers, manage tokens, and build landing apps.
1. [Appearance and commands](/docs/desktop-app/appearance-and-commands/): switch between light and dark themes and run
   any command from the command search.
1. [Keyboard shortcuts](/docs/desktop-app/keyboard-shortcuts/): every keyboard shortcut in Regressify Desktop, including
   the Source editor.
1. [Troubleshooting](/docs/desktop-app/troubleshooting/): fix common install, run, update, and deployment problems.
